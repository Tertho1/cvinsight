# CV Evaluator & Ranking System

An automatic CV evaluation, scoring, and ranking tool built with Python, spaCy, XGBoost, and Streamlit.

## Project Structure
See `PROJECT_PLAN.docx` for the full week-by-week plan.

## Setup

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

## Run the app

```bash
streamlit run app/app.py
```

## Stack
Python 3.14 | spaCy | XGBoost | Sentence-Transformers | Streamlit
