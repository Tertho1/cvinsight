# Docs — CV-Insight

Documentation index. Related files: `AGENTS.md` (agent guide + build order),
`TODO.md` (task tracking), `progress.md` (weekly progress), `project_plan.md`
(week-by-week roadmap + archived V2 proposals).

## Extraction & parsing

| Doc | Purpose |
|---|---|
| `extraction_audit.md` | Demo/corpus audit findings, fixes applied, prioritized improvements |
| `extraction_improvements.md` | Full improvement list with effort tiers ([P1]/[P2]/[P3]/[SKIP]) |
| `research_ner_hybrid_extraction.md` | 2021–2026 review: efficient NER for resume extraction, LLM-free |
| `research_text_reformatting.md` | 2021–2026 review: normalizing layout-broken CV text before extraction |
| `final_report.md` | Week 7 — consolidated evaluation metrics and final report |
| `matcher_datasets_latency.md` | Matcher datasets (with/without) survey, external dataset/method research (ConFit, contrastive fine-tune), latency measurements |

## Where each doc lives

- **Root:** `AGENTS.md`, `TODO.md`, `progress.md`, `project_plan.md`, `README.md`
  (Streamlit Cloud metadata + setup), `comparison_log.md`.
- **Docs:** this folder — anything about the extractor, scoring audit, or
  research that isn't a live status tracker.

## Conventions

- Mark **completed** items in the improvement/audit lists rather than deleting
  them, so decisions and effort stay visible.
- Benchmarks: `demo/benchmark/` (generated by
  `scripts/generate_benchmark_cvs.py`), baseline scores in
  `demo/benchmark/_baseline.json`.
- Live status lives in `TODO.md` / `progress.md`, not here.
